RehabVLM API

Send body joint positions from any camera or tracking system (Unity / VR body tracking, MediaPipe, Kinect, mocap) and get a range-of-motion assessment back in plain language and degrees.

1 · Get an API key

Free, instant, no sign-up. Store it like a password. Limit: 60 requests per minute per key.

2 · Call the API

  1. Download RehabVLMClient.cs (and optionally RehabVLMExample.cs) into Assets/.
  2. Add RehabVLMClient to a GameObject, paste your key, and drag in the Humanoid Animator of the tracked avatar (Meta Movement SDK, VRIK, Kinect, any pose-driven rig).
  3. Ask a question from code:
client.Assess("how is my left shoulder?", r => {
    feedbackText.text = r.answer;                 // "Left shoulder abduction 85 degrees, limited. ..."
    if (r.angles_deg.l_shoulder_abd > 120) Reward(); // drive gameplay with the numbers
});

The client sends 13 joints in the avatar's root space ("space": "unity", Y up, facing +Z), so the result doesn't depend on where the player stands in the room.

curl https://rehabvlm.vercel.app/api/v1/assess \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "which side is weaker?",
    "joints": {
      "nose": [0.30, 0.23], "l_shoulder": [0.40, 0.31], "r_shoulder": [0.26, 0.32],
      "l_elbow": [0.41, 0.20], "r_elbow": [0.17, 0.39], "l_wrist": [0.43, 0.10],
      "r_wrist": [0.10, 0.32], "l_hip": [0.41, 0.61], "r_hip": [0.33, 0.62],
      "l_knee": [0.45, 0.75], "r_knee": [0.35, 0.77], "l_ankle": [0.50, 0.88],
      "r_ankle": [0.34, 0.90]
    }
  }'
// landmarks = MediaPipe PoseLandmarker result.landmarks[0] (33 points)
const res = await fetch("https://rehabvlm.vercel.app/api/v1/assess", {
  method: "POST",
  headers: { "Authorization": "Bearer YOUR_KEY", "Content-Type": "application/json" },
  body: JSON.stringify({
    mediapipe: landmarks.map(p => [p.x * width, p.y * height]),

Reference

POST /api/v1/assess

jointsObject with 13 named points [x, y] or [x, y, z]: nose, l_/r_shoulder, l_/r_elbow, l_/r_wrist, l_/r_hip, l_/r_knee, l_/r_ankle. "l" = the person's own left.
mediapipeAlternative to joints: the 33 MediaPipe Pose landmarks as [x, y].
space"image" (default: x right, y down, person facing the camera) or "unity" (avatar root space: Y up, facing +Z).
questionFree text, matched to the closest task.
task / tasksOne or more of: describe, shoulders, elbows, hips, symmetry, weaker, exercise.

Response:

{
  "model": "rehabvlm-body-0.1",
  "answer": "The right side shows less range, 105 degrees less shoulder abduction.",
  "answers": { "weaker": "..." },
  "angles_deg": { "r_shoulder_abd": 58.5, "l_shoulder_abd": 163.8, "r_elbow_flex": 86.2,
                  "l_elbow_flex": 3.7, "r_hip_abd": 2.4, "l_hip_abd": 6.6, "trunk_lean": -8.2 },
  "latency_ms": 890
}

Errors come back as {"error": {"code", "message"}} with status 400 (bad input), 401 (bad key) or 429 (rate limited). GET /api/v1/health lists the available tasks.

Current model: full-body, frontal plane (arms, elbows, hips, trunk). A hand and finger model for hand-tracking apps is on the roadmap.

Research and education use only. Not a medical device.
