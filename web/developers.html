RehabVLM API

Send body joints or hand landmarks from any camera or tracker (Unity / VR body and hand tracking, MediaPipe, Kinect, mocap) and get a range-of-motion assessment back, in plain language and in degrees.

1 · Get an API key

Free, instant, no sign-up. Limit: 60 requests per minute per key.

API key

Environment variable: paste into your .env file or your host's env settings

Works with Vercel, Netlify, Render, GitHub Actions secrets, Docker --env-file, and Unity (see below). Keep .env out of git.

2 · Call the API

Every sample reads the key from REHABVLM_API_KEY, so your code never contains it.

  1. Download RehabVLMClient.cs (and optionally RehabVLMExample.cs) into Assets/.
  2. Provide the key. Create Assets/Resources/rehabvlm_env.txt containing the environment-variable line above (this works on Quest, Android and iOS too), or set REHABVLM_API_KEY in your environment for editor and desktop builds. Add the file to .gitignore.
  3. Add RehabVLMClient to a GameObject and drag in the Humanoid Animator of the tracked avatar (Meta Movement SDK, VRIK, Kinect, any pose-driven rig).
client.Assess("how is my left shoulder?", r => {
    feedbackText.text = r.answer;                    // "Left shoulder abduction 85 degrees, limited. ..."
    if (r.angles_deg.l_shoulder_abd > 120) Reward(); // drive gameplay with the numbers
});
  1. Install the XR Hands package (com.unity.xr.hands). It works with Meta Quest, Pico, Apple Vision Pro, Ultraleap and other OpenXR hand tracking.
  2. Download RehabVLMClient.cs and RehabVLMHandClient.cs into Assets/, and provide the key as in "Unity body".
  3. Add RehabVLMHandClient to a GameObject, pick the hand, and ask:
handClient.Assess("make a fist", r => {
    label.text = r.answer;   // "Average finger flexion 160 degrees, partial fist. Least flexed is the ring finger ..."

// Wrist: assign Elbow (or a body-tracked Humanoid Animator) and Tracking Space (XR Origin)

// Webcam hand tracker instead of XR? Send its 21 landmarks (MediaPipe order):

Reference

POST /api/v1/assess

Send either a body or a hand. Add an elbow to a hand to get wrist angles too.

jointsBody: object with 13 named points [x, y] or [x, y, z]: nose, l_/r_shoulder, l_/r_elbow, l_/r_wrist, l_/r_hip, l_/r_knee, l_/r_ankle. "l" = the person's own left.
mediapipeBody alternative: the 33 MediaPipe Pose landmarks as [x, y].
handHand: 21 landmarks [x, y, z] in MediaPipe Hands order (wrist; thumb CMC, MCP, IP, tip; then MCP, PIP, DIP, tip for index, middle, ring, pinky). Any orientation, scale or units.
elbowWrist: [x, y, z] of the same arm's elbow, in the same axes as hand (it may come from a body tracker; only the forearm direction is used).
handedness"left" / "right". Required for the wrist, because it decides which side is the palm (flexion vs extension).
model"wrist" selects the wrist model. Any question mentioning the wrist does the same.
space"image" (default) or "unity" (Unity's left-handed axes; body joints in avatar root space).
questionFree text, matched to the closest task.
task / tasksBody: describe, shoulders, elbows, hips, symmetry, weaker, exercise.
Hand: describe, fist, pinch, limited, spread, exercise.
Wrist: describe, bend, side, exercise.

Body response:

{
  "model": "rehabvlm-body-0.1",
  "answer": "The right side shows less range, 105 degrees less shoulder abduction.",
  "answers": { "weaker": "..." },
  "angles_deg": { "r_shoulder_abd": 58.5, "l_shoulder_abd": 163.8, "r_elbow_flex": 86.2,
                  "l_elbow_flex": 3.7, "r_hip_abd": 2.4, "l_hip_abd": 6.6, "trunk_lean": -8.2 },
  "latency_ms": 890
}

Hand response:

{
  "model": "rehabvlm-hand-0.1",
  "answer": "The ring finger has the least flexion, 45 degrees.",
  "answers": { "limited": "..." },
  "measurements": { "thumb_flex": 85, "index_flex": 250, "middle_flex": 250, "ring_flex": 45,
                    "pinky_flex": 250, "spread": null, "pinch_gap": 85 },
  "handedness": "right",
  "latency_ms": 640
}

Wrist response (model: "wrist", with elbow):

{
  "model": "rehabvlm-wrist-0.1",
  "answer": "Wrist flexion 60 degrees, full range. Typical flexion is 60 to 80 degrees.",
  "measurements": { ..., "wrist_flex": 60.2, "wrist_dev": -19.8 },
  "handedness": "right"
}

wrist_flex: + flexion (towards the palm), − extension. wrist_dev: + radial (thumb side), − ulnar. Hand requests that include an elbow also get these two values.

Finger flexion is summed over the finger's joints (MCP + PIP + DIP; thumb MCP + IP), so a full fist is about 250°. pinch_gap is the thumb-to-index distance as a % of hand width. spread is null while the fingers are too curled to measure.

Errors come back as {"error": {"code", "message"}} with status 400 (bad input), 401 (bad key) or 429 (rate limited). GET /api/v1/health lists the models and tasks.
